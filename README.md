An offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: the official list with saved progress, filters, a spoiler setting, a roadmap to the platinum, missable flags and a cited guide to every trophy. Unofficial fan project, not affiliated with Rockstar Games.

## Run it

```sh
node serve.ts   # then open the printed address; or open app/index.html directly
```
